1차원 리스트 — 나란히 놓인 상자들

리스트는 여러 값을 하나의 이름으로 묶어서 관리하는 자료구조입니다.
각 상자에는 인덱스(index)라는 번호가 붙어 있고, 0번부터 시작합니다.

학습 목표 확인하기
  • 리스트 만들기 (값 여러 개를 한 이름에)
  • 인덱스로 값 꺼내기 (0부터 · 음수 인덱스)
  • len( )과 인덱스 범위 오류

리스트 만들기

위에서 값을 입력하고 '시각화' 버튼을 눌러 보세요 ✨
인덱스는 0부터! — 리스트의 첫 번째 원소의 인덱스는 0입니다. 원소가 5개라면 인덱스는 0, 1, 2, 3, 4까지예요.
음수 인덱스 -1은 마지막 원소, -2는 뒤에서 두 번째를 가리킵니다.
list_1d.py 
# 리스트 만들기
scores = [85, 92, 78, 95, 88]

# 인덱스로 접근
print(scores[0])   # 85  (첫 번째)
print(scores[2])   # 78  (세 번째)
print(scores[-1])  # 88  (마지막)

# 값 변경
scores[1] = 100

# 추가 / 삭제
scores.append(70)   # 끝에 추가
scores.pop()         # 끝 원소 제거

# 길이
print(len(scores))   # 5
출력 예상해 보기 — 아래 코드의 결과는?
nums = [10, 20, 30] print(nums[-1])
출력: 30  — -1은 뒤에서 첫 번째(마지막) 칸

반복·조건 — 똑같은 일을 자동으로, 상황 따라 다르게

성적 5개를 합격/불합격으로 나눈다면 if를 5번 써야 할까요?
반복문(for)이 리스트를 한 칸씩 훑고, 조건문(if)이 매 칸마다 갈림길을 정합니다 — for 한 줄이면 5개든 100개든 똑같이 끝납니다.

학습 목표 확인하기
  • for 반복 (리스트·range 훑기)
  • range의 범위 (0부터 끝-1까지)
  • if 조건 분기 (합격/불합격 갈림길)

합격 판정 실험실

'▶ 실행'을 눌러 for가 상자를 하나씩 훑는 걸 지켜보세요 ✨
for는 반복, if는 갈림길. — for score in scores:는 리스트의 값을 하나씩 꺼내 같은 일을 반복합니다. 그 안의 if score >= 60:은 값에 따라 다른 길로 보냅니다.
range(5)는 0, 1, 2, 3, 4 다섯 개의 숫자를 만들어 줍니다 — "5번 반복"할 때 써요.
loop_if.py 
# 점수마다 합격/불합격 판정
scores = [85, 55, 92, 40, 78]
pass_count = 0

for score in scores:      # 한 칸씩 반복
    if score >= 60:       # 갈림길
        print(score, "합격")
        pass_count += 1
    else:
        print(score, "불합격")

print("합격 인원:", pass_count)

# range(n): n번 반복 (0부터 n-1까지)
for i in range(5):
    print(i)              # 0 1 2 3 4
출력 예상해 보기 — 아래 코드의 결과는?
for i in range(3): print(i, end=" ")
출력: 0 1 2  — range(3)은 0·1·2, 끝의 3은 빠짐

2차원 리스트 — 격자(표) 형태

2차원 리스트는 리스트 안에 리스트를 넣은 구조입니다.
행(row)과 열(column) 두 개의 인덱스로 원소를 찾아요. 마치 엑셀 표처럼요!

학습 목표 확인하기

2차원 리스트 만들기

격자 설정 후 '시각화' 버튼을 눌러 보세요 ✨

현재 리스트 코드
접근 방법: 리스트[행][열] — 먼저 몇 번째 행인지, 그다음 몇 번째 열인지 순서대로 씁니다. 예: matrix[1][2]는 2행(인덱스 1) 3열(인덱스 2)의 값이에요.
list_2d.py 
# 2차원 리스트 = 리스트의 리스트
matrix = [
    [1, 2, 3],   # 0행
    [4, 5, 6],   # 1행
    [7, 8, 9],   # 2행
]

# [행][열] 순서로 접근
print(matrix[0][0])  # 1  (0행 0열)
print(matrix[1][2])  # 6  (1행 2열)
print(matrix[2][1])  # 8  (2행 1열)

# 전체 순회
for row in matrix:
    for val in row:
        print(val, end=" ")
    print()  # 줄바꿈
출력 예상해 보기 — 아래 코드의 결과는?
m = [[1, 2], [3, 4]] print(m[1][0])
출력: 3  — [1]=두 번째 행 [3,4], 그 안의 [0]

데이터를 담는 변수·리스트에 이어, 동작을 묶는 함수와 설계도인 클래스까지 한눈에.

⚙️ 함수 — 입력→처리→출력 기계

재사용 가능한 코드 묶음
입력매개변수
처리함수 본체
출력return 값
한 번 정의 → 여러 번 호출

🏗️ 클래스 — 붕어빵 틀(설계도)

속성 + 기능을 하나로
속성변수(데이터)
기능메서드(함수)
인스턴스틀로 찍은 객체
클래스=틀, 객체=붕어빵
언제 무엇을? — 같은 작업을 반복하면 함수, 관련된 데이터와 기능을 한 덩어리로 묶고 싶으면 클래스를 씁니다.
functions.py 
# ─── 함수: 코드를 재사용하는 묶음 ───
def greet(name, times=1):       # 매개변수 name, 기본값 times=1
    for _ in range(times):
        print(f"안녕, {name}!")
    return len(name)            # 이름 길이를 반환

count = greet("민준")           # 안녕, 민준!
print(count)                    # 2   (반환값 활용)
greet("서연", 3)                # 안녕 3번 반복
classes.py 
# ─── 클래스: 속성 + 기능을 묶은 설계도 ───
class Student:
    def __init__(self, name, score):   # 생성자
        self.name = name               # 속성(인스턴스 변수)
        self.score = score

    def grade(self):                   # 메서드(기능)
        if self.score >= 60:
            return "합격"
        return "재시험"

s = Student("민준", 85)     # 인스턴스(객체) 생성
print(s.name)               # 민준
print(s.grade())            # 합격
함수 vs 클래스 
# 함수는 "동작" 하나,  클래스는 "동작 + 데이터" 묶음
add = lambda a, b: a + b     # 함수: 계산만
print(add(3, 4))             # 7

# 클래스: 데이터(잔액)와 동작(입금)을 함께 보관
class Account:
    def __init__(self, balance=0):
        self.balance = balance   # 인스턴스 변수
    def deposit(self, amount):
        self.balance += amount
        return self.balance

acc = Account(1000)
print(acc.deposit(500))      # 1500  (상태가 유지됨)
